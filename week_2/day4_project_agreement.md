# Project Agreement: Automated Attendance SMS Alert System

**Client**: School Administration  
**Developer**: Samuel Mwania  
**Project**: Automated Attendance Alert Script  
**Total Fee**: KES 22,000  

---

## 1. Project Overview
This agreement defines the exact scope, timeline, and payment terms for developing a lightweight Python automation script that reads weekly student attendance from an Excel spreadsheet and automatically sends SMS notifications to parents of students who have been absent 3 or more days that week.

---

## 2. Scope of Work

### Included in the Project
- **Attendance Spreadsheet Processing**: A Python script that reads the school's weekly attendance Excel workbook (.xlsx or .xls) and identifies students meeting the 3-day absence threshold.
- **SMS Gateway Integration**: Connection to an SMS provider API (such as Africa's Talking) to dispatch personalized alert messages containing the student's name and absence count to parent phone numbers.
- **Execution and Delivery Logging**: Automated generation of a timestamped log file recording processed records, successful SMS dispatches, and invalid or missing phone numbers.
- **Centralized Settings File**: A separate configuration file to adjust message templates, absence thresholds, and API keys without touching source code.
- **Setup Guide and Handover**: A clear setup guide and a 30-minute walkthrough call demonstrating how school staff run the script.

### Not Included in the Project
- **SMS Credit and Account Costs**: The school is responsible for creating its SMS gateway account and funding its own airtime/SMS units.
- **Data Entry and File Cleanup**: Manual cleaning of corrupt Excel files, mismatched parent contacts, or missing student entries.
- **Custom Web Interface or Mobile App**: The tool runs as a local Python script; building web dashboards or cloud hosting is excluded.
- **Biometric or Hardware Integration**: Direct integration with turnstiles, biometric scanners, or school management ERP databases.
- **Ongoing Weekly Operations**: School staff will execute the script weekly; ongoing administrative execution or long-term IT support is excluded.
